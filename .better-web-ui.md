## Design Context

### Users

Professionals who want CV rewriting, help applying to jobs, and interview preparation. They are evaluating a paid service on mobile or desktop. Nigeria and international opportunities are provisional audience contexts, not a verified market promise.

### Brand Personality

Assured, personal, optimistic. Working brand: Onward, explicitly authorised as a placeholder. Communicate practical support rather than promises of employment.

### Aesthetic Direction

Contemporary editorial: upright Manrope text with Instrument Serif display accents, pale ivory, ink, cobalt. Strong type, intentional composition, real photography, restrained motion. No neon, gradients, fake endorsements, or generic icon-card grids. Inspiration researched on Dribbble career and coaching landing pages; no design copied.

### Implementation Defaults

New project: React + TypeScript + Vite, plain CSS tokens, Lucide icons. Native dialog for intake preview, semantic HTML forms, no table or virtualisation libraries needed. CSS entrance choreography, IntersectionObserver section reveals, reduced motion support.

### Design Principles

Make the paid human service clear before conversion. Explain the work, not imaginary outcomes. Maintain readable contrast and generous touch targets. Use motion to explain hierarchy and give feedback. Landing page only; integrations later.
